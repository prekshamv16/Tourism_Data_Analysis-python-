# Tourism Data Analysis and Recommendation System

A Python-based mini project that analyzes tourism data and provides destination recommendations based on user preferences.

## Features
- Data Cleaning and Preprocessing
- Revenue Analysis by Tourism Category
- Tourism Category Distribution Visualization
- Revenue Analysis by Country
- Revenue Prediction using Linear Regression
- Tourist Recommendation System

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Dataset
Tourism dataset obtained from Kaggle for educational and academic purposes.

## Team Project
Developed as a group mini project by a team of 4 students.

## Run the Project
```bash
python tourism_analysis.py
```
